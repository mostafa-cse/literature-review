# Literature Review — Final Year Project

A web-based literature review management tool built as part of a Final Year Project.

## Features

- Browse and search academic literature
- Manage and organize research papers
- Backend API with Node.js
- Frontend interface for easy navigation

## Setup

### Prerequisites
- Node.js
- npm

### Installation

```bash
npm install
```

### Running the App

```bash
npm start
```

## Project Structure

```
├── Backend/        # Node.js backend API
├── Frontend/       # Frontend web interface
├── src/            # Source files
├── server.js       # Entry point
└── package.json    # Dependencies
```

> **Note**: The `literature.db` database file is not included in this repository (too large). You will need to set it up locally.
