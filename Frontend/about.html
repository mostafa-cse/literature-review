SUBSYSTEM I • DATA ENGINE

Relational SQLite WAL Engine & Dual-Storage Manuscript Redundancy

Unlike cloud-dependent web tools that lock your research behind proprietary servers, LitSphere operates locally with SQLite running in Write-Ahead Logging (WAL) mode. Every query executes sub-millisecond without network latency, and uploaded PDFs are preserved through dual-layer redundancy.

  • ✓ Dual-Layer Storage: PDFs are stored both in SQLite `paper_files` BLOB tables and on disk in `/uploads/` for offline safety.
  • ✓ Cascading Foreign Keys: `PRAGMA foreign_keys = ON;` guarantees that deleting a survey or paper cleanly purges child comments, file chunks, and metrics.
  • ✓ Zero Vendor Lock-In: Your entire survey database is a single atomic `.db` file that can be backed up or cloned anytime.
